Privacy Policy — SquishyCast

Last updated: 24 October 2026 · Android app com.pandaaz.squishycast

Developer: Panda.az Studio
Contact: hello@panda.az

SquishyCast is a game for children. We do not ask for, sell or share personal information. Optional video ads (Google AdMob), anonymous analytics and crash reports (Google Firebase) and an optional cloud backup work as described below.

What the game stores

Your toys, coins, in-game videos, studio name and settings are saved on your device. No account or registration is needed to play. The studio name you type stays on the device unless a grown-up turns on the optional cloud backup described below.

Optional video ads

  • Ads appear only when the player chooses to watch one ("Free box · watch a video" or "Wake up"). The game never shows ads by itself.
  • These videos come from Google AdMob, which is certified for the Google Play Families program. Every ad request is marked as directed to children (COPPA) and under the age of consent (GDPR), with the content rating limited to G. AdMob then shows only non-personalised, family-safe ads and does not use the advertising ID.
  • To show and count an ad, AdMob receives technical data such as the device model, operating system, app version and an approximate location from the IP address. See how Google uses data from apps that use its services.

Premium (one-time purchase)

  • A grown-up can buy Premium once (no ads, plus every dress-up part, song and backdrop). It sits behind a question for grown-ups and is paid through Google Play; we never see payment details.
  • Coins, boxes and anything random are never sold for real money. Coins are earned only by playing.
  • The game does not use the camera, the microphone, contacts or location. The "videos" are made inside the game; they leave the device only as part of the optional cloud backup.

Optional cloud backup

Cloud backup is off by default. If a grown-up turns it on in Settings, the game creates an anonymous ID (no name, no e-mail, no phone number) and keeps a copy of the game progress (coins, toys, in-game videos and the studio name) on our server so it can be restored on another phone with an 8-letter restore code. Only that anonymous ID can read or change its copy. The copy is stored with Supabase in the European Union (Frankfurt) and sent over an encrypted connection (HTTPS).

You can turn the backup off at any time in Settings. To delete the online copy, e-mail us the restore code and we will delete it.

Analytics and crash reports (Google Firebase)

The game uses Google Firebase Analytics, Crashlytics and Remote Config only to see which parts of the game work, to find and fix crashes, and to adjust game settings without an app update. It is used for app functionality, never for advertising.

  • What is collected: game events (for example a toy made or a box opened), crash reports and diagnostics (app version, device model, Android version, the stack trace of a crash) and the Firebase app instance ID. The advertising ID is not collected, ad personalisation is off, and no name, e-mail, photos, voice or location is collected.
  • Who processes it: Google, as our service provider (processor), only for this game. See Firebase privacy and security.
  • How long: analytics events are kept for up to 14 months; crash reports for up to 90 days.
  • Choices: clearing the app's storage or uninstalling the game resets the app instance ID. A parent can e-mail hello@panda.az to ask us to delete analytics data linked to the device.

Children

The game is made for children and follows the Google Play Families policy. It does not ask children for personal information.

Changes

If this policy changes, the new version will be posted on this page with a new date.
