Path puzzle: rules and strategy

Path is a path puzzle. Draw a single line that starts at 1, passes every number in order and fills every cell of the grid exactly once. Walls block the way. Each board has one solution.

Path rules

  • Start on 1 and end on the highest number.
  • Visit the numbers in order: 1, 2, 3 and so on.
  • The line must pass through every cell exactly once.
  • The line moves up, down, left or right and cannot cross a wall.

How to solve Path: 5 tips

1. Corners are easy

A corner cell has only two neighbours. Unless it is the start or the end, the line must enter through one and leave through the other.

2. Watch for dead ends

A cell with only two open neighbours is forced in the same way. Walls create many of these.

3. Never cut the board in two

If your line splits the empty cells into two separate areas, at least one of them can no longer be filled. Back up at once.

4. Plan between numbers

Look at how many cells lie between two numbers and how far apart they are. A short gap with a long distance tells you the path runs straight.

5. Work from both ends

The last number is the end of the line. Tracing back from it often settles the final part of the board.

Path puzzle FAQ

How do you play Path?

Draw one continuous line from 1 to the last number, visiting the numbers in order and filling every cell of the grid once.

Where can I play a new Path puzzle every day?

KinQueens for Android has a daily Path board, the same for every player, plus levels that grow from small warm-ups to large expert grids.

Can I undo moves in Path?

In KinQueens you drag back along the line to undo steps, and the undo button takes back any move.
